Three architectural alternatives

All three keep Phases 1–4 (schema + editor + parser + 8 seed templates). They diverge on what Phase 5 onward looks like.

Library hits (27–80%)
→ Copy template SCL
→ Form: wire IO slots
→ Done
Custom (20–73%)
→ Today's free-form path
→ AI generates from prose
→ Inconsistent output

A. Pure Library (current plan)

What it is: Ship the plan as written. Library covers what it covers; everything else uses the existing wizard authoring path.

Bet: Library will grow over time and 27% becomes 60% becomes 90%.

Verdict: Cheapest, least risky to current investment. But ignores the 73% problem on complex projects today, and "library will grow" depends on a promote-from-custom workflow that isn't in the plan.

B. Contract-as-Constraint Hybrid (my recommendation)

What it is: Interface contract is the universal authoring unit, not just for library assemblies. Custom assemblies = engineer authors the contract first, then AI fills in body SCL constrained by it. Library assemblies = template SCL pre-filled, contract already in DB.

Bet: The contract is what makes output consistent — the SCL underneath can be library-copied OR AI-generated. Same form in the wizard, same downstream consumers, same ProcessState wiring.

Verdict: Solves the 73% problem (custom gets the same structural rigour as library). Adds a "promote to library" path so the library grows project-by-project. Phase 5 stays mostly the same; new work is the AI-against-contract path + promote button.

C. Base + Variant Layers

What it is: Templates aren't atomic — they're a base + composable layers. A "weird conveyor" is conveyor_dol + 2 named layers. Layers are themselves library entries with their own contract patches and SCL fragments.

Bet: Most "custom" assemblies are 80% standard + a feature or two. Layers compose to cover the long tail without exploding template count.

Verdict: Most powerful conceptually but heavy lift. SCL composition is hard (variable scope clashes, ordering). Probably right for v2 but premature now — would delay shipping by months.
